# M5Stack Core2 台灣股票監測應用

在 M5Stack Core2 上運行的台股即時報價看板，支援 AI 分析（Gemini / Claude / OpenAI）與自動排程更新。

---

## 硬體需求

- **M5Stack Core2**（ESP32，320x240 IPS 觸控螢幕，16MB Flash，8MB PSRAM）
- USB-C 連接線（燒錄用）
- WiFi 網路

---

## 快速開始

需求：**docker** 或 **podman**（自動偵測），不需安裝 ESP-IDF。

### 燒錄

```bash
cd m5stack_stock

# 自動偵測 port，build + 燒錄 + 開啟 monitor
./flash.sh

# 指定 port
./flash.sh /dev/ttyUSB0

# 僅 build（不燒錄）
./flash.sh --build-only

# 清除所有設定後重新燒錄
./flash.sh --erase
```

## 操作說明

### 觸控螢幕操作

所有操作均透過 320x240 觸控螢幕進行，無實體功能按鈕。

#### 頂部狀態列（所有頁面共用）
```
[時間]     [頁面訊息（中間跑馬燈）]      [電量]
09:30      Dashboard - TWSE monitor      85%
```

- 左側：時間（`HH:MM`）
- 中間：頁面訊息（左右循環跑馬燈）
- 右側：電量百分比
- 版面限制：中間訊息為固定區塊，不會覆蓋左側時間與右側電量
- 切頁同步：切到 `Dashboard / Schedule / WiFi` 時，中間訊息會即時更新
- 字體顏色：狀態列三欄統一使用同一組文字顏色

| 操作 | 說明 |
|------|------|
| **掃描** | 搜尋附近 WiFi AP |

| **手機配網** | 啟動 SoftAP + 網頁設定，顯示 QRCode 供手機掃描 |

#### 手機配網（SoftAP + Web Portal）

點擊 **「手機配網」** 後，Core2 會啟動臨時 AP，並在螢幕顯示 QRCode（網址）。

1. 手機連線到 AP：`Core2-Setup`
2. 密碼：`core2wifi`
3. 掃描螢幕上的 QRCode（或手動開啟 `http://192.168.4.1`）
4. 在網頁輸入家中 WiFi `SSID/密碼` 並送出
5. 裝置成功連線後會自動儲存設定，後續開機自動重連

> 若開機時沒有已儲存的 WiFi 設定，系統也會自動啟動此 Portal 方便快速配網。

#### Portal 股票清單管理（TWSE-only）

Portal 首頁提供 Stocks 區塊，可直接管理觀察清單：

- 顯示目前清單（`symbol + name`）
- 新增代號（僅接受 4 位數；新增前即時向 TWSE 驗證）
- 刪除代號
- 上限固定 10 檔

限制與生效時機：

- 僅支援 TWSE（上市，`market=tse`），不支援 TPEx/OTC
- 清單異動後於下一個排程週期生效（不立即抓價）

## 常見問題

**Q: 燒錄失敗 "Failed to connect"**
- 確認 USB 線有資料傳輸功能（非僅充電線）
- 嘗試在燒錄時長按 Core2 左側螺絲旁的 Reset 鍵進入下載模式

**Q: 螢幕顯示後觸控無反應**
- 確認 I2C 連線正常（FT6336U 地址 0x38）
- 嘗試重啟裝置

**Q: TWSE API 回傳空資料**
- 確認目前是台股交易時段（09:00-13:30，週一至週五）
- 確認 WiFi 已連線

**Q: AI 分析失敗**
- 確認 API Key 正確且有效
- 確認帳戶有足夠額度
- AI API 請求超時上限為 30 秒
